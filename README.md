# 🐾 Animals Quiz Bot
Telegram-бот с викториной про животных.

## Описание
Учебный проект на Python с использованием aiogram.
Бот отправляет случайные факты о животных и предлагает угадывать животных по загадкам.

## Стек
* Python
* aiogram
* python-dotenv

## Запуск
git clone https://github.com/Ilyushkaa7/animalsbot.git
cd animalsbot
pip install -r requirements.txt

Создать файл `.env`:

BOT_TOKEN=your_token

Запуск бота:

python animal_bot.py

## Примечание
Проект создан в учебных целях для практики разработки Telegram-ботов.
